# AI_STRATEGY.md — Персональные AI-скилы и стратегия развития

## Как AI используется в разработке проекта (персональные скилы)

### Что делается с помощью AI

| Задача | Инструмент | Результат |
|---|---|---|
| Репозиторий (REPORT, PRODUCT, PLAN, AJTBD) | Claude (claude.ai) | Полный комплект документов |
| Avatar Engine — логика вычисления score | Claude Code | Python-модуль `avatar_engine.py` |
| AI Insights — интеграция с Anthropic API | Claude Code | Модуль `claude_insights.py` |
| Интерактивное демо аватара | Claude (Artifacts) | `demo.html` — живой прототип |
| Питч-сторилайн и нарративная дуга | Claude | Структура презентации |
| Анализ конкурентов и рыночные данные | Claude + поиск | Конкурентная матрица |

### Мой рабочий стек

```
Claude claude.ai     → стратегия, документы, питч, JTBD-анализ
Claude Code          → код продукта, скрипты, архитектурные решения  
Claude Artifacts     → интерактивные прототипы для демо
```

**Принцип работы:** AI не заменяет мышление — он ускоряет исполнение. Постановка задачи, проверка логики, итерации — мои. Написание кода и текста — AI.

## AI-стратегия развития продукта

### Уровень 1 — Сейчас (MVP, Year 1)

**Claude API для персональных инсайтов**

Архитектура: Avatar Engine вычисляет health score → формирует контекст → Claude генерирует текстовый инсайт.

```python
# Упрощённая схема
context = build_insight_context(metrics, score, state, history)
insight = claude_api.messages.create(
    model="claude-sonnet-4-20250514",
    system=SYSTEM_PROMPT,
    messages=[{"role": "user", "content": build_prompt(context)}]
)
```

Параметры: temperature 0.7 (живость текста), max_tokens 300, раз в день утром.

**Метрика успеха:** retention D30 ≥ 35% — гипотеза что персонализированные инсайты удерживают лучше generic рекомендаций.

---

### Уровень 2 — Год 2 (после 10k MAU)

**RAG на персональной истории**

Накапливаем историю пользователя (метрики + его реакции на инсайты) → строим векторное хранилище → Claude получает релевантный контекст из 30–90 дней истории.

Результат: инсайты перестают быть generic и становятся по-настоящему персональными («три недели назад ты пробовал ранний подъём — тогда HRV вырос на 12%»).

---

### Уровень 3 — Год 3 (после 50k+ пользователей)

**Fine-tuning на когортных данных**

С согласия пользователей — обучение модели на анонимизированных паттернах «метрики → реакция → результат». Модель начинает предсказывать не только что делать, но и почему это сработает для конкретного профиля.

## Конкурентный ров через AI

```
Конкурент копирует UI          → легко
Конкурент копирует интеграции  → сложно (6–12 мес)
Конкурент копирует персональную
модель пользователя за 2 года  → практически невозможно
```

AI — не фича. AI — механизм накопления данных о пользователе, которые со временем становятся рвом.
